Lesson 10: HTML Multimedia

Welcome to Lesson 10! In this lesson, we will learn how to add images, audio, videos and other multimedia elements to an HTML webpage.

1. What is HTML Multimedia?

HTML Multimedia means adding different types of media to a website. These include images, audio, videos and animations.

  • Images
  • Audio files
  • Video files
  • YouTube videos

2. Adding Images in HTML

The <img> tag is used to display images on a webpage. 

<img src="image.jpg"
     alt="Beautiful Nature"
     width="400">

Important Attributes:

  • src: Specifies the image location.
  • alt: Provides alternative text.
  • width: Sets image width.
  • height: Sets image height.

3. Adding Audio in HTML

The <audio> tag allows us to add sound or music to a webpage. 

<audio controls>

    <source src="music.mp3"
            type="audio/mpeg">

    Your browser does not support audio.

</audio>

Audio Attributes:

  • controls: Displays audio controls.
  • autoplay: Starts audio automatically.
  • loop: Plays audio repeatedly.
  • muted: Starts audio muted.

4. Adding Videos in HTML

The <video> tag is used to display video files on a webpage. 

<video width="500" controls>

    <source src="video.mp4"
            type="video/mp4">

    Your browser does not support video.

</video>

Video Attributes:

  • controls: Displays video controls.
  • width: Sets video width.
  • height: Sets video height.
  • poster: Displays a preview image.
  • loop: Repeats the video.

5. Adding YouTube Videos

We can also display YouTube videos on our webpage using the <iframe> tag. 

<iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="YouTube Video"
    allowfullscreen>
</iframe>
Remember: Replace VIDEO_ID with the actual ID of the YouTube video you want to display.

6. Understanding the iframe Tag

The <iframe> tag is used to display another webpage or external content inside your webpage. 

<iframe
    src="https://example.com"
    width="500"
    height="300"
    title="Example Website">
</iframe>

It can be used for maps, videos and other supported external content.

7. Image Width and Height

We can change the size of an image using width and height attributes. 

<img src="photo.jpg"
     width="300"
     height="200"
     alt="My Photo">
Tip: Keep the image's original proportions when resizing to avoid stretching or distortion.

8. Supported Media Formats

HTML supports different audio and video formats.

Audio Formats

  • MP3
  • WAV
  • OGG

Video Formats

  • MP4
  • WebM
  • OGG

9. Adding Multiple Sources

We can provide multiple media sources so the browser can choose a supported format. 

<video controls width="400">

    <source src="video.mp4"
            type="video/mp4">

    <source src="video.webm"
            type="video/webm">

    Your browser does not support video.

</video>

10. Figure and Figcaption

The <figure> tag groups media content, while <figcaption> provides a caption. 

<figure>

    <img src="nature.jpg"
         alt="Nature Image"
         width="300">

    <figcaption>
        Beautiful Nature
    </figcaption>

</figure>
