Lesson 5: HTML Lists

Welcome to Lesson 5! In this lesson, we will learn about HTML Lists. HTML Lists are used to display information in an organized way on a webpage.

1. What are HTML Lists?

HTML Lists are used to group related items together. They make information easier to read and understand. HTML provides three main types of lists:

  • Ordered List
  • Unordered List
  • Description List

2. Ordered List (ol)

An Ordered List displays items in a numbered sequence. It is created using the <ol> tag. Each item is written inside an <li> tag. 

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Output:

  1. HTML
  2. CSS
  3. JavaScript
Remember: The <ol> tag creates a numbered list, while the <li> tag creates each list item.

3. Types of Ordered Lists

We can change the numbering style using the type attribute. 

<ol type="A">
    <li>Apple</li>
    <li>Banana</li>
</ol>

<ol type="a">
    <li>Red</li>
    <li>Blue</li>
</ol>

<ol type="I">
    <li>First</li>
    <li>Second</li>
</ol>

Available types:

  • 1: Numbers (1, 2, 3)
  • A: Capital letters (A, B, C)
  • a: Small letters (a, b, c)
  • I: Roman numbers (I, II, III)
  • i: Small Roman numbers (i, ii, iii)

4. Unordered List (ul)

An Unordered List displays items using bullet points instead of numbers. It is created using the <ul> tag. 

<ul>
    <li>Mango</li>
    <li>Orange</li>
    <li>Banana</li>
</ul>

Output:

  • Mango
  • Orange
  • Banana

5. Types of Unordered Lists

The CSS list-style-type property can change bullet styles. 

<ul style="list-style-type: disc;">
    <li>Apple</li>
</ul>

<ul style="list-style-type: circle;">
    <li>Mango</li>
</ul>

<ul style="list-style-type: square;">
    <li>Orange</li>
</ul>

<ul style="list-style-type: none;">
    <li>Banana</li>
</ul>

6. Description List (dl)

A Description List is used to display a term and its description.

  • <dl>: Creates a description list.
  • <dt>: Defines a term.
  • <dd>: Defines the description.
<dl>
    <dt>HTML</dt>
    <dd>HTML creates the structure of webpages.</dd>

    <dt>CSS</dt>
    <dd>CSS styles webpages.</dd>
</dl>

Output:

HTML
HTML creates the structure of webpages.
CSS
CSS styles webpages.

7. Nested Lists

A Nested List is a list inside another list. It is useful for displaying categories and subcategories. 

<ul>
    <li>Programming
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>

    <li>Sports
        <ul>
            <li>Cricket</li>
            <li>Football</li>
        </ul>
    </li>
</ul>

Output:

  • Programming
    • HTML
    • CSS
  • Sports
    • Cricket
    • Football

8. Important HTML List Tags

  • <ol> - Ordered List
  • <ul> - Unordered List
  • <li> - List Item
  • <dl> - Description List
  • <dt> - Description Term
  • <dd> - Description Details
