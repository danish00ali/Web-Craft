Lesson 8: HTML Tables

Welcome to Lesson 8! In this lesson, we will learn how to create tables in HTML. Tables are used to organize information into rows and columns.

1. What are HTML Tables?

HTML Tables are used to display data in rows and columns. They make information organized and easier to understand.

For example, we can use tables to display student names, marks, subjects and other information.

2. The HTML Table Tag

The <table> tag is used to create a table in HTML. 

<table>

    <tr>
        <td>Name</td>
        <td>Age</td>
    </tr>

</table>

3. Understanding Table Tags

  • <table>: Creates a table.
  • <tr>: Creates a table row.
  • <td>: Creates a table data cell.
  • <th>: Creates a table heading cell.
  • <caption>: Adds a table title.

4. Creating Your First Table

Let's create a simple table containing student names and ages. 

<table border="1">

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Ali</td>
        <td>15</td>
    </tr>

    <tr>
        <td>Danish</td>
        <td>16</td>
    </tr>

</table>

Example Output:

Name Age
Ali 15
Danish 16

5. Adding Table Headings

The <th> tag is used to create headings inside a table. Browsers usually display table headings in bold text. 

<table>

    <tr>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

</table>

6. Adding Table Borders

We can use CSS to add borders around table cells. The border property creates lines around cells. 

<style>

table, th, td {
    border: 1px solid black;
    border-collapse: collapse;
}

</style>
Remember: The border-collapse property combines adjacent table borders into a single border.

7. Using Cell Padding

Cell padding creates space between the cell content and its border. 

table, th, td {
    border: 1px solid black;
    border-collapse: collapse;
}

th, td {
    padding: 15px;
}

8. Using Colspan

The colspan attribute allows a table cell to extend across multiple columns. 

<table border="1">

    <tr>
        <th colspan="2">Student Information</th>
    </tr>

    <tr>
        <td>Ali</td>
        <td>15</td>
    </tr>

</table>

Example Output:

Student Information
Ali 15

9. Using Rowspan

The rowspan attribute allows a table cell to extend across multiple rows. 

<table border="1">

    <tr>
        <th>Name</th>
        <td rowspan="2">Ali</td>
    </tr>

    <tr>
        <th>Student</th>
    </tr>

</table>

10. Table Caption

The <caption> tag adds a title to a table. It helps users understand what the table displays. 

<table border="1">

    <caption>Student Marks</caption>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Ali</td>
        <td>90</td>
    </tr>

</table>

11. Table Sections

HTML provides three useful tags for organizing table content:

  • <thead>: Contains the table heading rows.
  • <tbody>: Contains the main table data.
  • <tfoot>: Contains summary or footer rows.
<table border="1">

    <thead>
        <tr>
            <th>Product</th>
            <th>Price</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Book</td>
            <td>500</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <td>Total</td>
            <td>500</td>
        </tr>
    </tfoot>

</table>
