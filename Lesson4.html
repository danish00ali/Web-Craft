HTML Headings and Paragraphs

Learn HTML Step by Step - Lesson 4

Introduction Headings Paragraphs Examples

1. Introduction

HTML stands for HyperText Markup Language. It is used to create the structure of web pages. Headings and paragraphs are important elements of every HTML website.

Headings are used for titles and subtitles, while paragraphs are used to write text and information on a webpage.

2. What are HTML Headings?

HTML provides six different heading tags. These headings are used to organize content on a webpage.

HTML has six heading tags:

<h1>This is Heading 1</h1>

<h2>This is Heading 2</h2>

<h3>This is Heading 3</h3>

<h4>This is Heading 4</h4>

<h5>This is Heading 5</h5>

<h6>This is Heading 6</h6>

Heading Examples:

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6
Important Note: HTML has six heading levels. H1 is the highest-level heading, while H6 is the lowest-level heading.

3. What are HTML Paragraphs?

The HTML paragraph tag is used to write text on a webpage. The paragraph tag is written as <p>.

Paragraph Syntax:

<p>This is my first paragraph.</p>

<p>This is my second paragraph.</p>

Paragraph Output:

This is my first paragraph.

HTML is an easy language to learn. We can create beautiful websites using HTML.

4. Complete HTML Example

Here is a complete example of HTML headings and paragraphs in one webpage. 

<!DOCTYPE html>
<html>

<head>
    <title>My First Webpage</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <h2>About Me</h2>

    <p>
        My name is Danish.
        I am learning HTML.
    </p>

    <h2>My Education</h2>

    <p>
        I want to become a web developer.
    </p>

    <h3>Thank You!</h3>

</body>
</html>

5. Important Points to Remember

1. HTML has six heading tags: H1 to H6.

2. H1 is the highest-level heading.

3. H6 is the lowest-level heading.

4. The paragraph tag is written as <p>.

5. Headings are used for titles and subtitles.

6. Paragraphs are used to write information.
