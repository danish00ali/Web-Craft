Lesson 7: HTML Images

Welcome to Lesson 7! In this lesson, we will learn how to add images to webpages using HTML. Images make websites more attractive and informative.

1. What are HTML Images?

HTML Images are pictures displayed on a webpage. We use the <img> tag to add images to a website. The img tag is an empty element, which means it does not need a closing tag.

2. The HTML Image Tag

The <img> tag is used to display an image. The src attribute specifies the location of the image. 

<img src="flower.jpg" alt="A beautiful flower">

In this example, flower.jpg is the image file that the browser will display.

3. Understanding the src Attribute

The src attribute stands for Source. It tells the browser where to find the image. 

<img src="images/nature.jpg" alt="Beautiful nature">
Remember: The image path must be correct. Otherwise, the browser will not display the image.

4. The alt Attribute

The alt attribute provides alternative text for an image. It is useful when an image cannot load and for people using screen readers. 

<img src="cat.jpg" alt="A cute cat">
Important: Always write meaningful alt text for informative images.

5. Changing Image Width and Height

We can change the width and height of an image using the width and height attributes. 

<img src="flower.jpg"
     alt="Flower"
     width="300"
     height="200">

The width controls the image's width, while the height controls its height.

6. Adding Images from Another Folder

Images can also be stored inside a separate folder. We need to write the correct folder path in src. 

<img src="images/sunset.jpg" alt="Sunset">

In this example, the image is stored inside a folder named images.

7. Images from the Internet

We can also display an image using its online URL. 

<img src="https://example.com/flower.jpg"
     alt="A flower">
Remember: An online image must have a valid and accessible image URL.

8. Making an Image Clickable

We can make an image clickable by placing the img tag inside an anchor tag. 

<a href="https://www.google.com">
    <img src="google.png"
         alt="Google"
         width="200">
</a>

When someone clicks the image, the browser opens the linked webpage.

9. Responsive Images using CSS

Responsive images automatically adjust to fit different screen sizes. 

<img src="nature.jpg"
     alt="Beautiful nature"
     style="max-width:100%; height:auto;">
Tip: max-width: 100% prevents an image from becoming wider than its container, while height: auto preserves its proportions.

10. Important HTML Image Attributes

  • src: Specifies the image location.
  • alt: Provides alternative text.
  • width: Sets the image width.
  • height: Sets the image height.
  • loading: Controls image loading behavior.
  • title: Provides extra information.
