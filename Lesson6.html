Lesson 6: HTML Links

Welcome to Lesson 6! In this lesson, we will learn about HTML Links. Links are used to connect one webpage to another webpage or website.

1. What are HTML Links?

HTML Links are clickable elements that allow users to move from one webpage to another webpage. They are also called Hyperlinks.

Links make websites easier to navigate and help users find more information.

2. The HTML Anchor Tag

HTML uses the <a> tag to create hyperlinks. The href attribute specifies the destination of the link. 

<a href="https://www.google.com">
    Visit Google
</a>

Example Output:

Visit Google

3. Understanding the href Attribute

The href attribute tells the browser where the link should go when someone clicks it. 

<a href="https://www.youtube.com">
    Open YouTube
</a>
Remember: Without the href attribute, an anchor element does not work as a normal navigation link.

4. External Links

External Links connect your webpage to another website on the internet. 

<a href="https://www.wikipedia.org">
    Visit Wikipedia
</a>

Example Output:

Visit Wikipedia

5. Internal Links

Internal Links connect different pages of the same website. 

<a href="Lesson1.html">
    Go to Lesson 1
</a>

<a href="Lesson5.html">
    Go to Lesson 5
</a>

Example Output:

Visit Lesson 1 Visit Lesson 5

6. Open Links in a New Tab

The target="_blank" attribute opens a link in a new browser tab. 

<a href="https://www.google.com"
   target="_blank"
   rel="noopener noreferrer">
    Open Google in New Tab
</a>

Example Output:

Open Google in New Tab
Remember: target="_blank" opens the destination in a new tab. The rel attribute provides additional security.

7. Email Links

HTML can also create links that open the user's email application. 

<a href="mailto:example@gmail.com">
    Send Email
</a>

Example Output:

Send Email

8. Link to a Specific Section

We can use an element's id to create a link that jumps to a specific section of the same page. 

<a href="#about">
    Go to About Section
</a>

<h2 id="about">About Us</h2>
<p>Welcome to our website.</p>

Example Output:

Go to About Section

About Us

Welcome to our HTML learning website! We provide easy HTML lessons for beginners.

9. Image as a Link

We can make an image clickable by placing the <img> tag inside an <a> tag. 

<a href="https://www.google.com">
    <img src="google.png"
         alt="Google Logo"
         width="150">
</a>

When someone clicks the image, the browser opens the linked webpage.

10. Important HTML Link Attributes

  • href: Specifies the link destination.
  • target: Specifies where to open the link.
  • title: Provides extra information about the link.
  • rel: Defines the relationship between linked documents.
  • download: Suggests downloading the linked file.
