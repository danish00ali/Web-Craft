Lesson 9: HTML Forms

Welcome to Lesson 9! In this lesson, we will learn how to create forms in HTML. Forms are used to collect information from website visitors.

1. What are HTML Forms?

HTML Forms are used to collect information from users. For example, registration forms, login forms, contact forms and feedback forms.

Users can enter information into form fields and submit it.

2. The HTML Form Tag

The <form> tag is used to create an HTML form. Form elements are placed inside this tag. 

<form>

    <label>Name:</label>

    <input type="text">

    <button type="submit">
        Submit
    </button>

</form>

3. Text Input

The text input field allows users to enter ordinary text, such as their name or city. 

<label for="name">Your Name:</label>

<input type="text"
       id="name"
       name="name">

4. Password Input

The password input field is used to enter passwords. Characters are usually hidden while typing. 

<label for="password">Password:</label>

<input type="password"
       id="password"
       name="password">
Remember: A password field hides the characters visually. It does not encrypt or securely transmit the password by itself.

5. Email Input

The email input is used to collect email addresses. Browsers can check whether the entered value has a valid email format. 

<label for="email">Email:</label>

<input type="email"
       id="email"
       name="email"
       placeholder="Enter your email">

6. Number Input

The number input allows users to enter numeric values. 

<label for="age">Age:</label>

<input type="number"
       id="age"
       name="age"
       min="1"
       max="100">

7. Radio Buttons

Radio buttons allow users to select one option from a group of choices. 

<p>Choose your gender:</p>

<input type="radio"
       name="gender"
       value="male">
Male

<input type="radio"
       name="gender"
       value="female">
Female

Example Output:

Choose your favourite subject:

8. Checkboxes

Checkboxes allow users to select one or more options from a list. 

<p>Choose your hobbies:</p>

<input type="checkbox"
       name="hobby"
       value="cricket">
Cricket

<input type="checkbox"
       name="hobby"
       value="reading">
Reading

Example Output:

Select your hobbies:

9. Dropdown Lists

A dropdown list allows users to select an option from a list of choices. 

<label for="city">Choose a city:</label>

<select id="city" name="city">

    <option value="multan">Multan</option>
    <option value="lahore">Lahore</option>
    <option value="karachi">Karachi</option>

</select>

10. Textarea

The <textarea> tag creates a multi-line text field. It is useful for messages, comments and feedback. 

<label for="message">Your Message:</label>

<textarea id="message"
          name="message"
          rows="5"
          cols="30">
</textarea>

11. Submit and Reset Buttons

The Submit button sends form data to the destination specified by the form.

The Reset button restores form fields to their initial values. 

<button type="submit">
    Submit Form
</button>

<button type="reset">
    Reset Form
</button>

12. Important Form Attributes

  • action: Specifies where form data is sent.
  • method: Specifies how form data is sent.
  • name: Identifies a form field.
  • placeholder: Shows a helpful hint inside an input.
  • required: Makes a field compulsory.
  • value: Specifies an input's value.
  • min and max: Set minimum and maximum values.
Important: HTML creates the form interface, but sending and saving submitted information usually requires a server or a suitable form service.

13. Complete Registration Form Example

Here is an example of a simple registration form using different HTML form elements. 

<form>

    <label for="student-name">Name:</label>
    <input type="text"
           id="student-name"
           name="student-name"
           required>

    <label for="student-email">Email:</label>
    <input type="email"
           id="student-email"
           name="email"
           required>

    <label for="student-age">Age:</label>
    <input type="number"
           id="student-age"
           name="age">

    <label for="student-city">City:</label>
    <select id="student-city" name="city">
        <option>Multan</option>
        <option>Lahore</option>
    </select>

    <button type="submit">
        Register
    </button>

</form>
