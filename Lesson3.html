Lesson 3: HTML Attributes

Learn how HTML attributes work and how to use them in your websites.

1. What are HTML Attributes?

HTML attributes provide additional information about HTML elements.

Attributes are always written in the opening tag. They usually come in name and value pairs. 

<tagname attribute="value">

</tagname>
Example: 
<a href="https://www.google.com">
Visit Google
</a>
The href attribute tells the browser where the link should go.

2. The href Attribute

The href attribute is used with the <a> tag to create hyperlinks. 

<a href="https://www.google.com">
Visit Google
</a>
Output:

Visit Google

3. The src Attribute

The src attribute specifies the location of an image or other embedded resource. 

<img src="photo.jpg" alt="My Photo">

Here, src tells the browser which image it should display.

4. The alt Attribute

The alt attribute provides alternative text for an image. 

<img src="cat.jpg" alt="A cute cat">

If the image cannot load, the alternative text can help explain what the image represents.

5. Width and Height Attributes

Width and height specify the dimensions of an image. 

<img src="photo.jpg"
     alt="My Photo"
     width="300"
     height="200">

Width controls the width, while height controls the height.

6. The title Attribute

The title attribute provides extra information about an element. Browsers commonly show it as a tooltip when the user hovers over it. 

<p title="This is extra information">
Move your mouse over this text.
</p>

Move your mouse over this text.

7. The style Attribute

The style attribute is used to add CSS directly to an HTML element. 

<p style="color: blue;">
This is blue text.
</p>

This is blue text.

8. The id Attribute

The id attribute gives a unique identifier to an HTML element. 

<h2 id="heading">
My Heading
</h2>

An id can be used in CSS and JavaScript to select a particular element.

9. The class Attribute

The class attribute is used to assign one or more class names to HTML elements. 

<p class="important">
This is an important paragraph.
</p>

Multiple elements can share the same class.

10. The required Attribute

The required attribute makes a form field necessary before the form can be submitted. 

<input type="text" required>

The user must enter a value in this field before submitting the form.

11. Important Rules of HTML Attributes

  • Attributes are written in opening tags.
  • Attributes usually have a name and a value.
  • Attribute values should be placed inside quotation marks.
  • An element can have multiple attributes.
  • Some attributes, such as required, are Boolean attributes.
<img src="photo.jpg"
     alt="A photo"
     width="300"
     height="200">
